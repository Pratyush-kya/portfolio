# Engineering Portfolio — Pratyush Kiran Rath

> **Live Deployment:** [pratyushrath.vercel.app](https://pratyushrath.vercel.app)  
> **Built with:** Next.js 16 (App Router, SSG), React 19, TypeScript, Tailwind CSS v4, Lucide Icons.

---

## 🎯 Architecture & Guiding Philosophy

This portfolio is engineered around radical honesty, defensible metrics, and high-performance minimalist architecture:
* **Static Site Generation (SSG):** Pre-rendered static HTML with zero server cold starts and sub-second load times.
* **Defensible Metrics:** Every number presented (29/29 PyTests, 0.00 MB/s disk I/O, 0 bytes external upload) is backed by test runs or browser network proofs.
* **Accessibility First:** Tested for keyboard navigation, visible focus rings (`focus-visible:ring-2`), and `prefers-reduced-motion` compliance.
* **Privacy by Default:** Zero tracking cookies, zero analytics bloat, and client-side processing wherever possible.

## 🛠️ Tech Stack

* **Framework:** Next.js 16.4.5 (App Router, Static Export)
* **UI & Styling:** React 19, Tailwind CSS v4
* **Icons:** Custom SVG icons & Lucide React

## 🚀 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Pratyush-kya/portfolio_pratyush.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build production static bundle:
   ```bash
   npm run build
   ```
